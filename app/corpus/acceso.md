# Manual de acceso

## Recuperar acceso
Si no puede ingresar a la plataforma, seleccione Recuperar acceso en la pantalla de inicio e ingrese su correo institucional. El sistema envía un enlace temporal. Si el enlace no llega, revise la carpeta de spam y espere cinco minutos; no basta con repetir el envío del enlace varias veces seguidas.

## Error 403
El error 403 indica que el sistema reconoció a la persona pero no autoriza el recurso solicitado. Este error no demuestra por sí solo que la cuenta esté bloqueada. Para reportarlo, adjunte una captura con el mensaje visible e incluya la fecha y el recurso al que intentó acceder.

## Consulta de estados
El código SOL-1001 identifica una solicitud de ejemplo, pero este manual no contiene los estados individuales de las solicitudes. Para conocer el estado actual de una solicitud use la consulta de estado con su código.

## Olvidé mi contraseña
Si olvidó su contraseña, use la opción Recuperar acceso con su correo institucional y siga el enlace temporal para crear una nueva. Nunca escriba su contraseña en este chat ni la comparta con otras personas.

## No me llega el correo de recuperación
Verifique que escribió bien su correo institucional, revise la carpeta de spam y espere cinco minutos antes de pedir otro enlace. Si después de eso no llega, radique una solicitud de acceso para soporte técnico.

## Mi cuenta está bloqueada
Después de varios intentos fallidos la cuenta puede bloquearse de forma temporal. Espere treinta minutos y vuelva a intentar. Si sigue bloqueada, radique una solicitud de acceso e indique la fecha y la hora del bloqueo.

## Ingreso por primera vez
La primera vez ingrese con su correo institucional y la contraseña temporal que recibió. El sistema le pedirá cambiarla antes de continuar. Si no recibió la contraseña temporal, use Recuperar acceso.

## La plataforma no carga o va lenta
Pruebe con otro navegador, cierre y vuelva a abrir la página y revise su conexión a internet. Si el problema continúa, radique una solicitud de acceso con una captura de pantalla y la hora en que ocurrió.

## Error 404 o página no encontrada
El error 404 significa que la dirección no existe o fue movida. Vuelva a la pantalla de inicio de la plataforma y entre desde el menú en lugar de usar un enlace guardado.
