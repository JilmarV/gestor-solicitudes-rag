# Tipos de solicitud

## Tipos disponibles
El gestor reconoce cuatro tipos de solicitud: acceso, documento, pago y queja. Cada solicitud recibe un código con el formato SOL-0000 y se asigna a un único tipo.

## Cómo elegir el tipo
Use el tipo acceso cuando no puede ingresar a la plataforma. Use documento para constancias y certificados. Use pago para cobros, recibos o vencimientos. Use queja para inconformidades sobre un servicio.

## Tipo acceso
El tipo acceso cubre contraseñas olvidadas, cuentas bloqueadas, el error 403 y problemas para entrar a la plataforma. Lo atiende soporte técnico.

## Tipo documento
El tipo documento cubre constancias de estudios y de matrícula, certificados de notas, paz y salvo y la corrección de datos en esos documentos. Lo atiende la oficina de registro académico.

## Tipo pago
El tipo pago cubre recibos de pago, comprobantes que no aparecen, cobros y vencimientos. Lo atiende tesorería.

## Tipo queja
El tipo queja cubre inconformidades sobre un servicio o una atención recibida. Lo atiende la coordinación del servicio.

## El código SOL-0000
El código tiene la letra SOL, un guion y cuatro dígitos, por ejemplo SOL-1001. Se asigna cuando la solicitud queda radicada y no cambia. Sirve para consultar el estado y para hablar con el área responsable.

## Mi caso no encaja en ningún tipo
Si su caso no corresponde a acceso, documento, pago ni queja, se trata como una consulta general o se escala a revisión humana. Cuéntelo con detalle para que se asigne el área adecuada.

## Un mensaje con dos asuntos
Cada solicitud tiene un único tipo. Si tiene dos asuntos distintos, por ejemplo una constancia y un pago, radique una solicitud para cada uno.
