# Ejemplos de solicitudes

## Ejemplo de acceso
Un mensaje como no puedo entrar a la plataforma o me sale el error 403 es una solicitud de acceso, de prioridad media, que atiende soporte técnico.

## Ejemplo de documento
Un mensaje como necesito una constancia de estudios es una solicitud de documento, de prioridad media, que atiende la oficina de registro académico.

## Ejemplo de pago urgente
Un mensaje como mi pago vence mañana es una solicitud de pago con prioridad alta, que atiende tesorería, por vencer en menos de 48 horas.

## Ejemplo de queja
Un mensaje como el trato que recibí en la atención fue malo es una queja, de prioridad media, que atiende la coordinación del servicio.

## Ejemplo de consulta de estado
Un mensaje como cómo va SOL-1001 es una consulta de estado. El gestor usa el código y responde con el estado y el área que atiende la solicitud.

## Ejemplo de caso para una persona
Un mensaje que menciona acoso, amenazas o una demanda no se responde automáticamente: se deriva a revisión humana y lo contacta la coordinación del servicio.
